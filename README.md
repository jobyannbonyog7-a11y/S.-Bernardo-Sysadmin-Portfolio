# System Administrator Career Portfolio

A cool, professional, interactive web portfolio showcasing the System Administrator profession.

## Features

- **Soft Pink & Purple Design**: Muted pink and purple accents with comfortable dark and light themes
- **Dark / Light Mode**: Seamless theme switching
- **Particle Background**: Animated floating particles with connections
- **Interactive Elements**:
  - Click tool cards for detailed modal + particle burst
  - Click developer profile picture for fairy dust / glitter effect
  - Click developer name for surprise glitch + glow effect
- **Linux Terminal**: Browser-based command prompt simulation with common Linux commands
- **Fully Responsive**: Works beautifully on desktop, tablet, and mobile
- **Smooth Animations**: Glitch title, floating icons, skill bars, server rack animation

## How to Use

1. Open `index.html` in any modern browser
2. Or serve with a local server:
   ```bash
   npx serve .
   # or
   python -m http.server 8000
   ```

## Customization

- **Change Developer Name**: Edit the text in the About section
- **Update About Info**: Modify the paragraphs and course information
- **Add Your Photo**: Replace the image path in the `<img id="profile-pic">` tag
- **Social Links**: Update the `href` attributes in the social buttons
